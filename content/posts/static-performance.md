静态站点的优势是部署简单，但“没有后端”不等于“性能自动很好”。用户真正等待的是从请求发出到内容可读的全过程。

## 排查顺序

1. 先看网络面板，确认最大的资源和阻塞请求。
2. 再看首屏布局，避免图片或字体加载后发生明显位移。
3. 最后检查交互脚本，把不影响首屏的工作延后。

这次博客改造后，首页只加载一个小型交互脚本；文章内容在构建期完成，浏览器不需要再下载 Markdown 解析器。

~~~ts
const searchable = title + ' ' + description + ' ' + tags.join(' ');
const matches = searchable.toLowerCase().includes(query);
~~~

性能优化不是追逐一个孤立的分数，而是让用户更快看到内容，更快得到交互反馈。
